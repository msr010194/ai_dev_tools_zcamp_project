# ai_dev_tools_zcamp_project
Final project for DataTalksClub course - https://datatalks.club/courses/ai-dev-tools-zoomcamp/

## Running the tests

Backend (Python 3.12+, [uv](https://docs.astral.sh/uv/)):

```
cd backend
uv sync
uv run pytest
```

Frontend (Node 20+):

```
cd frontend
npm install
npm test
```
